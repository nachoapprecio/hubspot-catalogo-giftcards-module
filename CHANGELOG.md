# Changelog

Todos los cambios notables de este proyecto serán documentados en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2025-07-17

### Agregado
- ✨ Módulo HubSpot inicial con funcionalidad completa
- 🎨 Control total de personalización visual desde CMS
- ⚙️ 10 grupos de configuración con 80+ opciones
- 🌈 Selector de colores para fondos, títulos, botones
- 📝 Selector de fuentes Google Fonts integrado
- 🎭 Configuración de bordes y sombras personalizables
- ✨ Animaciones de entrada configurables (Fade, Slide, Zoom)
- 📱 Configuración responsive específica para móvil
- 📊 Tracking integrado (Google Analytics + HubSpot)
- 🔧 Callbacks JavaScript personalizables
- 🐛 Modo debug para desarrollo
- 🔗 Soporte completo para URL parameters
- 📄 Contenido editable (títulos, subtítulos, pie de página)
- 🎯 Filtros por país y categoría configurables

### Configuración Incluida
- **Países soportados**: Chile, Perú, Colombia, México, Ecuador
- **Categorías**: E-commerce, Gastronomía, Supermercados, Grandes Tiendas, Servicios
- **Plantillas compatibles**: PAGE, BLOG_POST, LANDING_PAGE
- **Responsive breakpoints**: Configuración móvil personalizable

### Archivos del Módulo
- `module.html` - Template principal con variables HubL
- `module.css` - Estilos personalizables vinculados al CMS
- `module.js` - JavaScript con configuraciones dinámicas
- `fields.json` - Configuración completa del editor
- `meta.json` - Metadatos del módulo

### Documentación
- `README.md` - Documentación principal
- `docs/installation.md` - Guía de instalación detallada
- `docs/configuration.md` - Referencia de configuración
- `docs/examples.md` - Ejemplos de uso

### Técnico
- Compatibilidad con HubSpot CMS Hub
- Carga automática de assets externos
- Optimización para rendimiento
- Validación de configuraciones
- Control de errores y fallbacks
